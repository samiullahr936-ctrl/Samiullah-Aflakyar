# Samiullah-Aflakyar
Personal profile of Samiullah Aflakyar — Poet, Writer, Researcher, and Psychology Student
سمیع الله افلاکیار شاعر، نویسنده، پژوهشگر و دانشجوی روان‌شناسی از افغانستان است. او به روان‌شناسی، علوم شناختی، فلسفه، ادبیات، عرفان و شناخت انسان علاقه‌مند است و می‌کوشد میان اندیشهٔ علمی و آفرینش ادبی پیوند برقرار کند. فعالیت‌های او در زمینهٔ شعر و داستان‌نویسی، مطالعه و پژوهش در روان‌شناسی و اندیشه‌های فلسفی و عرفانی شکل گرفته است.
